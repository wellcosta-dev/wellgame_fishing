# wellgame_fishing

FiveM / QBCore port of MTA `v4_fishing`.

## Használat

1. Add items: bot + damil + úszó + csali (`/giveitem`)
2. Használd a **damil** majd **úszó** itemet (felszereli az első botra)
3. Használd a **horgászbotot**
4. **RMB** célzás, **LMB** töltés/dobás (vízpart)
5. Kapáskor **görgő fel** → horog; behúzás; landolás
6. Hal **használata** a felvásárlónál (blip) → eladás minigame
7. **Horgászláda** használata → jutalom

## Admin

`/fishinghelp` — rövid segítség

## Config

- `Config.Dropoffs` — GTA V felvásárló pozíciók
- `Config.EconomyScale` — eladási ár skála (alap 0.001)

Reference only: `v4_fishing/`
